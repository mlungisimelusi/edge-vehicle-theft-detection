Communication design

LoRa is the primary channel for all routine telemetry between the mobile node and this gateway. The GSM module (SIM800C) stays registered on the network but transmits only when an alert must go out: a theft alert from the Isolation Forest model, a follow-up location update, or a loss-of-contact alert when a vehicle stops reporting — never for routine telemetry. This dashboard reads the shared SQLite database the gateway writes to, including a status heartbeat the gateway updates every few seconds. It never talks to the LoRa or GSM hardware directly, so restarting the dashboard never affects detection or alerting.
